# Claude Usage OSD

แอป macOS แบบ menu-bar ที่แสดงสถานะการใช้งาน Claude (รายวัน/รายสัปดาห์) เป็นวงแหวนเกจ พร้อมตัวจับเวลานับถอยหลังจนกว่าโควต้าจะรีเซ็ต

## สิ่งที่ต้องมีก่อนติดตั้ง

- macOS 13 หรือใหม่กว่า
- Xcode Command Line Tools — ติดตั้งด้วยคำสั่ง:
  ```bash
  xcode-select --install
  ```
- `jq` — ติดตั้งด้วย Homebrew:
  ```bash
  brew install jq
  ```

## ขั้นตอนติดตั้ง

### 1. โคลนโปรเจกต์

```bash
git clone <this-repo-url>
cd ClaudeOSD
```

### 2. รันสคริปต์ติดตั้ง

```bash
./setup.sh
```

สคริปต์นี้ทำ 2 อย่าง:

1. **เชื่อมต่อข้อมูลใช้งานจริง** — ฝัง hook เข้าไปใน `~/.claude/statusline-command.sh` เพื่อให้ Claude Code เขียนข้อมูลการใช้งาน (% ใช้ไปของวันนี้/สัปดาห์นี้, เวลารีเซ็ต, ค่าใช้จ่าย) ลงไฟล์ที่แอปนี้อ่านได้ เพราะ Claude ไม่มี public API สำหรับข้อมูลนี้ ข้อมูลจะหลุดออกมาทาง stdin ของ statusLine เท่านั้น ระหว่างที่มี session ของ Claude Code ทำงานอยู่
   - ถ้ามี `~/.claude/statusline-command.sh` ของตัวเองอยู่แล้ว สคริปต์จะ**ไม่แก้ไฟล์ให้อัตโนมัติ** แต่จะพิมพ์โค้ดที่ต้องเอาไปแปะเองออกมาทางหน้าจอ
2. **คอมไพล์และติดตั้งแอป** — รัน `swift build -c release`, ติดตั้งไปที่ `~/Applications`, เซ็นโค้ดแบบ ad-hoc, และลงทะเบียนให้เปิดอัตโนมัติตอน login

### 3. เปิดแอป

หลังสคริปต์รันจบ เปิด **Claude Usage OSD** จาก `~/Applications` ได้เลย หรือรีสตาร์ท Mac ก็จะเปิดเองอัตโนมัติ

> เกจจะแสดง "—" จนกว่าจะมีการเรียก Claude Code API ครั้งถัดไป (เพราะ statusline จะอัปเดตเฉพาะตอนที่มีการตอบกลับจาก API เท่านั้น)

## อัปเดตแอปหลัง pull โค้ดใหม่

ถ้าดึงโค้ดใหม่มาแล้วแค่ต้องการ build/ติดตั้งซ้ำ โดยไม่ต้องรัน setup สถานะ statusline ใหม่:

```bash
./build_app.sh
```

## คำสั่งอื่นที่ใช้ตอนพัฒนา

```bash
swift build              # build อย่างเดียว
swift run                # รันแอปแบบ dev (ไม่ติดตั้งเป็น .app)
swift build -c release   # build แบบ release
```
